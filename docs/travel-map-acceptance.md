# 游记移动地图验收

验收日期：2026-10-14。环境：macOS arm64、Node.js 24.13.1。

对象：[六月九日 · 从关西机场到京都](../demo/pages/posts/79ee39fe-312d-4ffe-9397-3d602da52f9e.md)，9 个地点、10 段相机路径（包括开头和结尾的总览）。

## 实现与资源

MapLibre Native + sharp 预生成沿途相机采样。页面在 Canvas 2D 中对已解码图片做连续 Mercator 投影，随阅读进度平移、缩放；附近的参考画面在同一相机位置短暂混合。生成与站点构建均不需要 Playwright 或 Chromium。

[生成清单](../demo/public/travel-maps/2cb18dabc42a29db2248/map.json)为 v2，包含 `renderer: maplibre-native`、相机采样、时间参数和四套图片地址。

连续移动检查记录了 Canvas 绘图参数：相邻 1 px 滚动中，图片 URL 保持不变，绘制位置和缩放连续变化。它验证了移动发生在已加载图片上，而非仅在固定地点换图。

另在桌面延迟目标图片响应后迅速滚回，确认迟到图片不会覆盖当前阅读位置；下一场景图片返回 404 时，仍保留完整地图，不回退到实时瓦片。快速跳到缓存之外时，允许短暂停留在旧画面，待附近画面解码后继续跟随。

缓存使用 16 × 1024 × 1024 像素预算，约 64 MiB RGBA，Canvas 与混合所用画面另计。单元测试覆盖 LRU 淘汰、目标保留、并发与队列优先级、失败重试节制、卸载后的回调处理。路径测试覆盖相机插值、重复坐标和各类视口下的完整画面覆盖。
